Design Decisions

こだわりポイント

01
アクセスキー完全排除
GitHub Actions の認証を OIDC に移行。長期クレデンシャルをゼロにし、漏洩リスクを排除した。
02
SSH ポートの廃止
22番ポートを完全クローズ。SSM Session Manager によりアウトバウンド HTTPS のみでセキュアなサーバーアクセスを実現。
03
意図的にシンプルに保つ
ALB・ASG・NAT GW は使用しない設計を選択。静的サイトに不要なコストを排除し、構成の意図を説明できる状態を維持。
